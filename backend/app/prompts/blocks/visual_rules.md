Visual rules: each scene describes exactly one visual moment in its English `visual_prompt`. Never repeat the same `visual_type` more than two scenes in a row. Keep prompts simple and filmable as a single still image: one subject, one action, one setting. Images are drawn WITHOUT text: never ask for drawn text, letters, numbers, logos, or watermarks inside the image; the factory adds the scene's `keyword_text` locally at render time instead, so compose so the top area of the frame can carry that overlay, with the subject in the upper-middle and not pressed against the very top. Compose for a vertical 9:16 frame with the subject in the upper-middle area.
